## Connection Setup

### Create Sentry Auth Token

1. Log in to your [Sentry account](https://sentry.io/).
2. Open **Settings** and select your organization.
3. Go to **Auth Tokens** under **Developer Settings**.
4. Click **Create New Token**, select the required scopes (e.g. `project:read`), and create the token.
5. Copy the token and paste it into the connection.
