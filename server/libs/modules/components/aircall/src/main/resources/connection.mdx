## Connection Setup

### Create Aircall API Keys

1. Log in to the [Aircall Dashboard](https://dashboard.aircall.io).
2. Go to **Integrations & API** and open the **API Keys** section.
3. Create a new API key to generate an **API ID** and **API Token**.
4. Copy the **API ID** into the "API ID" field and the **API Token** into the "API Token" field of the connection.
