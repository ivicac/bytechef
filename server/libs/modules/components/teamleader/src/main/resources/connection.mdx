## Connection Setup

### Create Teamleader OAuth2 Integration

1. Log in to the [Teamleader Marketplace](https://marketplace.focus.teamleader.eu/) as a developer.
2. Create a new integration to obtain a **Client ID** and **Client Secret**.
3. Set the redirect URI shown in the ByteChef connection dialog.
4. Enter the client id and client secret into the connection and authorize access.
