## Connection Setup

### Get CoinGecko Demo API Key

1. Log in to your [CoinGecko](https://www.coingecko.com) account.
2. Open the [Developer Dashboard](https://www.coingecko.com/en/developers/dashboard) and
   create a **Demo API key**.
3. Copy the key into the connection. For very low request volumes the key can be left
   empty.
