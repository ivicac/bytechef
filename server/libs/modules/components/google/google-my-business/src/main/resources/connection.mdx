## Connection Setup

### Create Google Cloud OAuth Client

1. In the [Google Cloud console](https://console.cloud.google.com), enable the **My Business Business Information API** (access requires Google approval).
2. Create OAuth client credentials with the `https://www.googleapis.com/auth/business.manage` scope.
3. Set the redirect URI to the callback URL provided by ByteChef.
4. Copy the **Client ID** and **Client Secret** into the connection.
