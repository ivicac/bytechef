## Connection Setup

### Create Google OAuth2 Credentials

1. Open the [Google Cloud Console](https://console.cloud.google.com/).
2. Create or select a project and enable the **Google Analytics Data API**.
3. Go to **APIs & Services → Credentials** and create an **OAuth client ID** of type Web application.
4. Add the redirect URI shown in the ByteChef connection dialog.
5. Enter the client id and client secret into the connection and authorize access.
