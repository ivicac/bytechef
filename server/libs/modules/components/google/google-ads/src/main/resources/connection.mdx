## Connection Setup

### Create Google Ads API Access

1. Request a **developer token** in your Google Ads manager account under **Tools** -> **API Center**.
2. In the [Google Cloud console](https://console.cloud.google.com), create OAuth client credentials with the `https://www.googleapis.com/auth/adwords` scope.
3. Set the redirect URI to the callback URL provided by ByteChef.
4. Copy the **Client ID**, **Client Secret**, and **Developer Token** into the connection.
