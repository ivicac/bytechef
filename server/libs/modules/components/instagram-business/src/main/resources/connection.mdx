## Connection Setup

### Create Facebook App

1. Create an app in the [Meta developer portal](https://developers.facebook.com).
2. Add the Facebook Login product and request the `instagram_basic`, `instagram_content_publish`, `business_management`, and `pages_show_list` permissions.
3. Set the redirect URI to the callback URL provided by ByteChef.
4. Copy the **App ID** and **App Secret** into the connection. The Instagram account must be a professional account linked to a Facebook page.
