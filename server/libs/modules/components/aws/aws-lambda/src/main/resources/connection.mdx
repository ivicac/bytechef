## Connection Setup

### Create AWS Credentials for Lambda

1. Open the [AWS IAM console](https://console.aws.amazon.com/iam/) and create a user with the `AWSLambda_FullAccess` policy (or a narrower invoke policy).
2. Create an access key for the user and copy the **Access Key ID** and **Secret Access Key** into the connection.
3. Enter the region where your Lambda functions are deployed (e.g. us-east-1).
