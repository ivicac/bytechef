## Connection Setup

### Create AWS Credentials for Transcribe

1. Open the [AWS IAM console](https://console.aws.amazon.com/iam/) and create a user with the `AmazonTranscribeFullAccess` policy and read access to the S3 bucket containing your media files.
2. Create an access key for the user and copy the **Access Key ID** and **Secret Access Key** into the connection.
3. Enter the region where Transcribe should run (e.g. us-east-1).
