## Connection Setup

### Create AWS Credentials for Textract

1. Open the [AWS IAM console](https://console.aws.amazon.com/iam/) and create a user with the `AmazonTextractFullAccess` policy and read access to the S3 bucket containing your documents.
2. Create an access key for the user and copy the **Access Key ID** and **Secret Access Key** into the connection.
3. Enter the region where Textract should run (e.g. us-east-1).
