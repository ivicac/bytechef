## Connection Setup

### Create a Clay Table Webhook

1. Log in to [Clay](https://app.clay.com) and open the table you want to send records to.
2. Add a new source and choose the **Webhook** (Monitor Webhook / Pull data from webhook) option.
3. Copy the generated webhook URL and paste it into the **Webhook URL** field of the connection.
4. (Optional) If you enabled webhook authentication in Clay, copy the auth token and paste it into the **Auth Token** field. It is sent as the `x-clay-webhook-auth` header on each request. Leave it empty if your webhook does not require authentication.
