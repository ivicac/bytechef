## Connection Setup

### Create Apaleo OAuth2 Client

1. Log in to your [Apaleo account](https://app.apaleo.com/).
2. Open **Settings** and select **Connected apps**.
3. Create a new connected app with the authorization code flow to obtain a **Client ID** and **Client Secret**.
4. Set the redirect URI shown in the ByteChef connection dialog.
5. Enter the client id and client secret into the connection and authorize access.
