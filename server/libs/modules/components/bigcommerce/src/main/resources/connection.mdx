## Connection Setup

### Create a BigCommerce Store API Account

1. Log in to your BigCommerce store control panel.
2. Open **Settings → API → Store-level API accounts**.
3. Create a new API account and select the OAuth scopes you need (for example, read access to Products and Customers).
4. Copy the generated **Access Token** and the **Store Hash** from your store's API path and paste them into the connection.
