## Connection Setup

### Register a Blackboard REST API Application

1. Register an application on the [Anthology Developer Portal](https://developer.anthology.com)
   to obtain an **application key** and **secret**.
2. In your Blackboard Learn instance, open **System Admin → REST API Integrations** and add
   the application ID with a user that has the required permissions.
3. Enter the instance URL, application key and secret into the connection.
