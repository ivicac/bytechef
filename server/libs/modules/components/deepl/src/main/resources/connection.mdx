## Connection Setup

### Create DeepL API Key

1. Create a [DeepL API account](https://www.deepl.com/pro-api). You can choose the free or pro plan.
2. Log in and open your [account settings](https://www.deepl.com/account/summary).
3. Go to the **API keys** tab.
4. Copy your authentication key and paste it into the connection.

Free plan keys end with `:fx` and are routed to the free API endpoint automatically.
