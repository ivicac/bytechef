## Connection Setup

### Create OpenWeather API Key

1. Create an account on [OpenWeather](https://home.openweathermap.org/users/sign_up).
2. Log in and open the [API keys](https://home.openweathermap.org/api_keys) tab of your account.
3. Copy the default key or generate a new one, then paste it into the connection.

New API keys can take a couple of hours to activate.
