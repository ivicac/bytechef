## Connection Setup

### Enable the Obsidian Local REST API Plugin

1. In Obsidian, install and enable the **Local REST API** community plugin.
2. Open the plugin settings and copy the **API key** and the server URL (e.g. https://127.0.0.1:27124).
3. Paste both into the connection. The Obsidian vault must be reachable from the ByteChef server.
