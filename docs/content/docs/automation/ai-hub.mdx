The **AI Hub** is the conversational home of your automation workspace. It gathers every way you talk to AI in ByteChef — the general-purpose assistant, your saved personal agents, and chat-enabled workflows — into one sidebar of conversations, with shared attachments, memory, and model selection.

## Working in a conversation

{/* TODO screenshot: conversation composer close-up — model picker dropdown open showing catalog models, microphone and attachment buttons visible */}

- **Model picker** — choose which activated [AI provider](/platform/ai-providers) and model answers each conversation; different conversations can run on different models.
- **Attachments and files** — the paperclip button (and drag-and-drop) upload files into a conversation, and anything the assistant produces (files, charts, data tables, knowledge bases, workflow executions, workflows, custom components, code workflows) opens in a viewer panel beside the chat.
- **Reference resources** — the **+** button opens a resource picker for referencing an existing file, workflow, data table, knowledge base, or execution in the message. The reference is added as context the assistant can read and also opens in the right-hand panel.
- **Connectors** — the connectors button lists the component connectors you've added, each with an on/off toggle for this conversation, plus a **Manage connectors** link to add more or configure their tools. Enabled connectors let the assistant act in those apps on your behalf.
- **Specialist agents** — alongside the general assistant, the AI Hub routes to focused Ask + Build specialists. The `custom_component_agent` lists, explains, creates, and updates [custom components](/enterprise/extensibility/custom-components), and the `code_workflow_agent` does the same for [code workflows](/enterprise/extensibility/code-workflows). Referenced custom components and code workflows appear in the conversation sidebar and open — editable — in the right panel.
- **Voice** — the microphone button in the composer starts a spoken interaction instead of typing.
- **Memories** — durable facts the assistant learns are saved automatically and listed on the **Memories** page, where you can review and delete them. The same auto-memory capability is available inside workflow [AI Agents](/platform/ai/agent) via the Agent Utils **Auto Memory** tool, scoped to the deployment instead of the user.
- **Skills** — type `/` at the start of the composer to open a picker over your [skills](/platform/ai/agent/skills) (the same set as the **AI → Skills** page); selecting one inserts `/skill-name` and the assistant consults that skill's content to steer the run.
- **Tasks sidebar** — every conversation is listed in the collapsible sidebar, grouped by kind, so you can return to or archive past threads.

## Managing connectors and MCP servers

The **Manage connectors** link in the composer's connectors menu opens the AI Hub's connectors page, where you decide which tools the assistant can call. It has two lists.

{/* TODO screenshot: AI Hub connectors page — the component connectors list (each row with an enable toggle, a tools chevron, and an ellipsis menu) above the custom MCP servers list, with the Add connector and Add MCP server buttons */}

### Component connectors

1. Click **Add connector** and pick a component from the grid.
2. If the component needs a connection and none exists yet, its row shows a **Connect** action — click it to create or choose a connection in the **Connect** dialog. (The row's ellipsis menu also offers **Connect** to change the connection later.)
3. Toggle the connector **on/off** to control whether the assistant may use it at all.
4. Expand the row's **tools** chevron to enable or disable individual actions, and click a tool's **Configure** (gear) button to preset parameter values for it, so the assistant only has to supply the rest.
5. Remove a connector from the ellipsis menu's **Delete**.

### Custom MCP servers

1. Click **Add MCP server** and fill in a **Name**, the **Server URL**, and an optional **Bearer token** (stored encrypted server-side).
2. Expand the server row to see its tools, which are discovered live from the server; toggle the whole server or individual tools on and off.
3. Remove a server from its row's delete action.

Per-conversation, the composer's connectors menu still lets you toggle any enabled connector on or off for just that chat — this page sets what is available in the first place.

## Enabling the AI Hub

The AI Hub is an Enterprise Edition surface, disabled by default:

```
BYTECHEF_AI_HUB_ENABLED=true
```

It uses the models you activate in [AI Providers](/platform/ai-providers), so at least one chat provider must be configured for the environment.
