Every project on ByteChef consists of one or more workflows. Projects help organize and manage workflows, making it
easier to group related automation processes together.

## Create Project

{/* TODO screenshot: Projects page with the Create Project dialog open — name and description fields and the Create button */}

1. Navigate to the **Projects** tab.
2. Click on the **New Project** button located in the top right corner.
3. Enter a name for your project. Optionally, provide a description, select a category, and add relevant tags.
4. Click **Save**.

The dropdown arrow next to the **New Project** button offers three more ways to start a project: **From Template**, **Import Project**, and **New Code Workflow**.

## Create Project from Template

1. Click the dropdown arrow next to the **New Project** button in the top right corner.
2. Select **From Template** from the dropdown menu.
3. Browse the template gallery, pick a pre-built or community-shared project template, and import it.

For details on the gallery and the import flow, see [Templates](/automation/templates).

## Import Project

1. Click the dropdown arrow next to the **New Project** button in the top right corner.
2. Select **Import Project** from the dropdown menu.
3. Choose the project archive (`.zip`) file exported from ByteChef.
4. The imported project, together with its workflows, appears in the project list.

## New Code Workflow

1. Click the dropdown arrow next to the **New Project** button in the top right corner.
2. Select **New Code Workflow** from the dropdown menu.
3. Give the code workflow a name and pick its language, then edit the workflow definition directly in code.

A code workflow runs on the same engine as a visually built one — see [Build Approaches](/automation/build/build-approaches) for when to choose full-code.

## Edit Project

1. Locate the project you wish to edit and click on the three dots next to its name.
2. Select **Edit** from the dropdown menu.
3. Modify the project name, description, category, or tags as needed.
4. Click **Save** to apply your changes.

## Duplicate Project

1. Find the project you want to duplicate and click on the three dots next to its name.
2. Select **Duplicate** from the dropdown menu.
3. The duplicated project will appear in the project list with the same name followed by a numerical suffix (e.g.,
   Project Name (1)).

## Export Project

1. Click on the three dots next to the project name you wish to export.
2. Select **Export** from the dropdown menu.
3. A project archive (`.zip`) containing the project and all of its workflows downloads to your computer. Use it to back up a project or import it into another workspace or ByteChef instance.

## Import Workflow

1. Click the dropdown arrow next to the **Workflow** button on the project where you want to import a workflow.
2. Select **Import Workflow** from the dropdown menu.
3. Choose the JSON file containing the workflow you wish to import.

## Import n8n Workflow

1. Click the dropdown arrow next to the **Workflow** button on the project where you want to import a workflow.
2. Select **Import n8n Workflow** from the dropdown menu.
3. Choose the JSON file exported from n8n.
4. ByteChef converts the n8n workflow and adds it to the selected project.

## Publish Project

1. Click on the three dots next to the project name you wish to publish.
2. Select **Publish** from the dropdown menu.
3. Provide a description for this published version to document any changes or updates.
4. Click **Publish** to make the project available.

## Share Projects and Workflows as Templates

<Callout type="warn" title="Coming soon">
    Sharing projects and workflows as templates is on the upcoming release track and is not yet
    available in the latest released version of ByteChef.
</Callout>

Beyond [exporting a project](#export-project) to a `.zip` file for your own backups, a project — or
an individual workflow, from its own three-dot menu — can be shared as a **template** that anyone
with the link can import into their own workspace.

1. Click on the three dots next to the project (or workflow) name and choose **Share**.
2. Write a **Description** of what it does — this is required before you can export it.
3. Click **Export and generate template link**. The dialog turns into a link card with a **Copy
   link** button; anyone who opens the link can import it through `/import/shared/projects/{uuid}`
   (workflows use `/import/shared/workflows/{uuid}`).
4. Use the toggle at the top of the dialog to **disable** the link at any time — the existing link
   stops working — and to re-enable it later, which generates a fresh export.
5. If you keep editing the project after sharing it, the dialog notes that "an older version... is
   shared as a template" and offers an **Update template based on the current version** button, so
   the link always points at what you intend.

<!-- TODO screenshot: Share project dialog with an active template link and the Copy link button -->

A second, separate action — **Share with Community** — opens ByteChef's public template submission
form in a new tab, for projects and workflows you want listed in the official gallery (see
[Templates](/automation/templates)) rather than shared privately by link.

## Delete Project

1. Locate the project you want to delete and click on the three dots next to its name.
2. Select **Delete** from the dropdown menu.
3. Confirm the deletion if prompted.
